# Granular

A local note editor focused on precise, character-level text highlighting.

## Run locally

Requirements: Node.js LTS and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

To verify the production build:

```sh
npm run build
```

The note is stored in this browser's local storage. No account or server is required.
